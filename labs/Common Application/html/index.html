Challenge Rules & Conditions

  • Reconnaissance: Map out the subdomains and enumerate running services and versions using manual enumeration methods (API endpoints, default paths, HTTP headers).
  • Exploitation: Exploit known vulnerabilities and misconfigurations discovered during enumeration.
  • Flags: Each service contains hidden flags. Retrieve them by following the attack chains learned in the HTB Academy.
  • Restrictions: Internal file systems of the subdomains are purposefully hidden from this visual map. You must gain RCE or LFI to explore them.
  • Hint: Start by doing directory brute-forcing on this main gateway.
